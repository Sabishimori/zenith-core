# Zenith Core

Zenith is a gaming companionship platform designed to help players meet, connect, and play together. It matches players on conversation and safety rather than rank, owning the space between matches: identity, discovery, live voice, and an economy rewarding participation.

## Repository Structure

- **`zenith-web/`** — Main web application built with Vite, React, Motion, and Three.js / React Three Fiber.
- **`PRODUCT.md`** — Product truth, status, audience, and core platform concepts.
- **`DESIGN.md`** — Design system tokens, color palettes, typography, and visual rules.
- **`CONTENT.md`** — Copywriting and messaging framework.
- **`STRUCTURE.md`** — Concept page architecture and dossier outline.
- **`CLEO-REFERENCE.md`** — Reference teardown and design system notes.
- **`mobie main screens/`** — Mobile screen designs and UI mockups.
- **`img/`** — Brand assets and iconography.

## Getting Started (Web App)

```bash
cd zenith-web
npm install
npm run dev
```

To build for production:

```bash
cd zenith-web
npm run build
npm run preview
```
